# Order Analysis System

A Python-based order analysis project that processes order data from JSON files and generates business insights.

## Features
- Total revenue calculation
- Best-selling revenue-generating product analysis
- Customer spending analysis
- Top 3 customers identification
- CSV report generation

## Technologies
- Python
- JSON
- CSV

## Output
The program generates a structured CSV report containing revenue statistics and customer spending summaries.
